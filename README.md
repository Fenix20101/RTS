# Стальной рубеж

Оригинальная браузерная RTS про Вторую мировую в духе классических тактических стратегий.

**Играть в браузере:** https://fenix20101.github.io/RTS/

**Версия для Windows:** [SteelFront.exe](https://github.com/Fenix20101/RTS/raw/main/dist/SteelFront.exe) — скачать и запустить (нужен Microsoft Edge WebView2, в Windows 10/11 обычно уже есть).

## Управление
- ЛКМ — выбрать, рамка — выделить группу, ПКМ — идти / атаковать
- A — атака с ходу, S — стоп, H — не стрелять
- Z / X — пехота: лечь / встать, R — развернуть технику
- Колесо мыши — приближение (до 4,5×)
- F1 в игре — полная справка
